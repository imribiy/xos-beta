# XOS Developer Betas

Developer beta builds of the [XOS playbook](https://github.com/imribiy/xos-playbook), for testers. **Downloads:** see [Releases](https://github.com/imribiy/xos-beta/releases).

Betas are tested only in virtual machines, not on real hardware. Back up important files, keep a Windows setup USB at hand and expect bugs. For everyday use, take the newest stable release from [xos-playbook](https://github.com/imribiy/xos-playbook/releases) instead.

## Update channels

AME Wizard's **Updates** button follows the channel of the playbook you load:

- A beta build checks this repository, so it offers the next beta (or the next stable release, which is published here as well).
- A stable build checks [xos-playbook](https://github.com/imribiy/xos-playbook), which carries stable releases only, so it never offers a beta.

The beta source code is on the [`dev` branch of xos-playbook](https://github.com/imribiy/xos-playbook/tree/dev). Report problems in [xos-playbook Issues](https://github.com/imribiy/xos-playbook/issues) and name the beta version. The installation guide and FAQ are in [imribiy/XOS](https://github.com/imribiy/XOS).
